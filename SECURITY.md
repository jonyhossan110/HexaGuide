# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |

## Reporting a Vulnerability

If you discover a security issue in HexaGuide itself, please **do not** open a public GitHub issue.

Email us privately at: **contact@hexacyberlab.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond within 72 hours.
